# SauceDemo Automation Testing Project

## About Project
This project is created to practice Selenium WebDriver automation testing using Java.

## Technologies Used
- Java
- Selenium WebDriver 4.35.0
- TestNG 7.11.0
- Maven

## Project Type
Web Application Automation Testing

## Application Tested
https://www.saucedemo.com/

## Test Coverage

- Valid Login
- Invalid Login
- Empty Username and Password
- Empty Password
- Locked Out User Login
